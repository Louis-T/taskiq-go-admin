Settings

Retention

How long task information is kept before the automatic cleanup deletes it.

Between {{.Min}} and {{.Max}} minutes (~1 year). Leave empty to disable the cleanup. Tasks queued more than this long ago are deleted every {{.PurgeInterval}}, in batches of {{.PurgeBatchSize}} rows so that incoming task reports are never blocked.

Stuck tasks

Flag tasks as stale when no report arrived for too long, for example because the worker died or the middleware's report was lost. Stale tasks are only flagged, never modified: a late report still updates them.

Leave empty to disable. Set them above your longest normal run and queue times.

Redis streams

Every stream in this Redis database with a consumer group is trimmed. Only entries acknowledged by every group are removed.

Leave the interval empty to turn the automatic trim off. 0 minutes trims acknowledged entries as soon as possible. Saving does not trigger a run; the cleaner reads the settings on its next tick.
